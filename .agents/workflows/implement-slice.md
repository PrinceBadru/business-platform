# Implement Slice

Use this workflow to build a bounded slice without drifting beyond the approved scope.

## Flow

1. Confirm the plan and acceptance criteria.
2. Implement the smallest viable change in the correct module.
3. Keep interfaces narrow and explicit.
4. Add validation for domain and security rules.
5. Run the relevant test and verification steps.

## Exit condition

The slice is ready for review only when the behavior is proven, the code remains within boundaries, and the evidence is documented.
