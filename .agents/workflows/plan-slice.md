# Plan Slice

Use this workflow to turn a request into a clear, reviewable engineering slice.

## Steps

1. Capture the business goal and success criteria.
2. Identify the domain module and affected surfaces.
3. Note data, auth, and operational constraints.
4. Split the task into bounded implementation steps.
5. Define verification and rollout criteria.

## Output

Provide a brief implementation plan with scope, assumptions, risks, and a verification gate.
