# Start Day

Use this workflow to establish momentum and keep delivery disciplined.

## Daily routine

1. Review the current goals and known blockers.
2. Confirm the highest-priority safe slice.
3. Verify the relevant security and testing constraints.
4. Begin with the smallest achievable implementation step.
5. Capture evidence before pausing or handing off work.

## Success condition

The day ends with clear progress, known risks, and next actions documented for the next handoff.
