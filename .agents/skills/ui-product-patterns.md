# UI Product Patterns

Use this skill for interface design, user-journey review, and product-facing front-end patterns.

## Core expectations

- Prefer clear information hierarchy and predictable flows.
- Keep primary tasks short, legible, and recovery-friendly.
- Ensure loading, empty, and error states are designed intentionally.
- Aim for strong accessibility and clear state transitions.

## Checklist

- Validate the flow matches the user’s mental model.
- Ensure the UI communicates state changes and consequences.
- Review contraints for mobile, accessibility, and keyboard navigation.
- Ensure actions map cleanly to trusted business rules.

## Deliverable

Provide a product-oriented summary describing the interaction pattern, edge cases, and success/error states for the feature.
