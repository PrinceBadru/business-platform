# Browser Verification

Use this skill for validating front-end behavior in a real browser environment.

## Expectations

- Check the happy path and the obvious failure path.
- Confirm that client-side validation and loading states behave as expected.
- Verify key flows without relying on the implementation details alone.
- Capture evidence of successful interaction before release.

## Checklist

- Page loads render expected content.
- Form submission and validation rules behave as designed.
- Errors are surfaced clearly and recoverably.
- Protected routes and auth flows enforce the intended state.

## Output

Report the observed behavior, any mismatches with the intended design, and the exact verification steps used.
