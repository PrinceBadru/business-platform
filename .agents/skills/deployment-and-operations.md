# Deployment and Operations

Use this skill when preparing for rollout, runtime operations, monitoring, and production support.

## Areas to review

- Build and release process
- Environment configuration and secrets management
- Health checks and observability
- Backup, restore, and incident playbooks
- Resource constraints and operational tolerances

## Checklist

- Confirm deployment is reversible or staged safely.
- Validate monitoring signals and alerting thresholds.
- Review configuration drift and infrastructure assumptions.
- Ensure operational runbooks exist for common issues.

## Handoff expectation

Capture the release summary, rollback guidance, and runtime responsibilities in a handoff-ready artifact.
