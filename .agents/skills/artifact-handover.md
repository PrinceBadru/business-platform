# Artifact Handover

Use this skill to package implementation evidence and operational summaries for a production handoff.

## Required artifacts

- Summary of what changed
- Risk profile and mitigation notes
- Verification evidence
- Operational runbook links or instructions
- Deployment and rollback notes

## Standards

- Prefer compact, reviewable handoff documents over ad hoc notes.
- Include evidence from tests and browser verification when available.
- Record any assumptions or follow-up work clearly.

## Outcome

The receiving team should be able to make an informed decision about shipping, monitoring, and support without additional discovery work.
