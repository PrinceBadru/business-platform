# Feature Implementation

Use this skill when planning or building a new business capability that spans product, data, and delivery concerns.

## Delivery workflow

1. Confirm the feature scope and acceptance criteria.
2. Identify the affected domain modules and interfaces.
3. Design the minimal schema and user-facing changes required.
4. Implement with explicit validation and edge-case handling.
5. Verify coverage with tests and review the security implications.

## Checklist

- Feature boundaries are explicit and reviewable.
- API and persistence contracts are typed and narrow.
- Dependency injection and module boundaries remain clean.
- Rollback or operational mitigations are considered.

## Completion signal

A feature can be considered ready only when the intended behavior is validated, the risks are documented, and the handoff artifacts are created.
